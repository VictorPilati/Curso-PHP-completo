
 # 📘 Curso Completo de PHP – Do Zero ao Avançado
 
 Este repositório contém todo o conteúdo do meu curso completo de PHP, com teoria, exercícios e projetos práticos divididos em módulos. Ideal para quem está começando ou quer revisar/aprimorar seus conhecimentos em PHP.
 
 ---
 
 ## 📚 Estrutura do Curso
 
 ### 🔰 Módulo 1 – Fundamentos do PHP (Básico)
 - Introdução ao PHP
 - Sintaxe básica
 - Variáveis e tipos de dados
 - Operadores e estruturas de decisão
 - Funções simples
 - Formulários com `POST`
 - Projeto: [Calculadora Simples](./modulo-1-fundamentos/projeto-calculadora/calculadora.php)
 
 ---
 
 ### 🧰 Módulo 2 – PHP Intermediário
 - Arrays simples e associativos
 - Funções personalizadas
 - Manipulação de arquivos
 - Sessões e cookies
 - Upload de arquivos
 - Projeto: Sistema de Cadastro (sem banco)
 
 ---
 
 ### 🗃️ Módulo 3 – PHP + MySQL (CRUD)
 - Conexão com banco de dados (`mysqli` e `PDO`)
 - Inserção, leitura, atualização e exclusão de dados
 - Segurança básica (SQL Injection, Prepared Statements)
 - Projeto: Agenda de Contatos com CRUD
 
 ---
 
 ### 🧑‍💻 Módulo 4 – PHP Avançado e Estrutura MVC
 - Organização em MVC (Model-View-Controller)
 - URLs amigáveis com `.htaccess`
 - Níveis de acesso e autenticação
 - Envio de e-mails com `PHPMailer`
 - Projeto: Sistema de Login com Níveis de Acesso
 
 ---
 
 ### 🚀 Módulo 5 – Projeto Final: CMS de Blog
 - Cadastro de usuários
 - Login e autenticação
 - Publicação de postagens com imagem
 - Painel administrativo
 - Projeto: Sistema de Blog com painel admin
 
 ---
 
 ## 🛠 Tecnologias Usadas
 
 - PHP 8.x
 - HTML5 + CSS3
 - MySQL
 - Apache (XAMPP)
 - Git & GitHub
